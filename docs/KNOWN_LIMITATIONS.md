# 알려진 제한사항

- 네이버 이미지 PDF는 CPU OCR 시간이 페이지 수에 비례해 늘어납니다.
- 제공된 27페이지 네이버 자료 중 대표 1페이지만 검증했으며 나머지는 사용자 요청으로 생략했습니다.
- 발급처 레이아웃이나 문구가 변경되면 전용 파서 규칙 보완이 필요할 수 있습니다.
- 일반 파서는 오탐을 줄이기 위해 적은 필드만 추출하며 자동 회계 확정을 목표로 하지 않습니다.
- OCR 저신뢰 결과와 금액 불일치는 사용자가 원본을 보고 확인해야 합니다.
- 현재 배포 형태는 Python 소스이며 단독 실행 EXE/MSI 설치 프로그램은 포함하지 않습니다.
- OCR 모델은 최초 사용 시 다운로드되므로 첫 실행에는 인터넷 연결과 추가 디스크 공간이 필요합니다.
- 실제 영수증 파생 Excel은 개인정보 보호를 위해 GitHub 배포물에 포함하지 않습니다.
