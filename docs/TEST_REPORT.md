# 테스트 및 검증 보고서

## 자동 테스트

개발 중 마지막으로 완료한 빠른 테스트 실행 결과는 총 33개 통과였습니다.

- 데이터 모델, 설정, 로깅 마스킹
- 날짜·금액·식별번호 정규화
- 쿠팡·네이버 파서와 문서 분류
- 사업자번호·금액·중복·상태 검증
- 파일 로더와 PDF 추출 분기
- Excel 4개 시트 생성·형식·재열기
- PySide6 기본 화면과 테이블 편집

사용자가 최종 개발 단계에서 테스트 생략을 요청했으므로, 배포 문서 정리 후 전체 테스트는 다시 실행하지 않았습니다.

## 실제 예시 자료

| 자료 | 검증 범위 | 결과 |
|---|---:|---|
| 쿠팡 영수증 PDF | 18/18페이지 | 18건 분류·파싱, 공급가액 존재 확인 |
| 네이버 영수증 PDF | 대표 1/27페이지 | 네이버 분류, 판매자·가맹점·사업자번호·일자·금액 관계 확인 |
| 네이버 영수증 PDF | 나머지 26페이지 | 사용자 요청으로 생략 |

네이버 대표 페이지 OCR 신뢰도는 약 0.9815였고, 대표 데이터를 포함한 Excel 19건 생성 단계까지 확인했습니다. 이 파일은 실제 영수증에서 파생되므로 Git 추적 대상에서 제외했습니다.

## 미검증 영역

- 네이버 예시 PDF 나머지 26페이지의 OCR 일관성
- 설치가 깨끗한 신규 Windows PC에서의 처음부터 끝까지 설치
- 네트워크가 차단된 환경의 최초 OCR 모델 준비
- 실행 파일 또는 설치 프로그램 패키징
- 새로운 쿠팡·네이버 발급 양식과 기타 쇼핑몰 양식
